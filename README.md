# TBI GEHU Website

A modern web platform being developed for the Technology Business Incubator (TBI), Graphic Era Hill University. The project aims to provide a centralized ecosystem for startups, mentors, investors, and students through incubation programs, events, resources, and innovation initiatives.

🚧 Currently under development as part of the TBI GEHU Internship Program.

**Tech Stack:** React.js • Node.js • Express.js • MongoDB • Tailwind CSS
